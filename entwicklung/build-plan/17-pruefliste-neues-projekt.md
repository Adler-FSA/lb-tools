# 17 – Prüfliste für ein neues Softwareprojekt

Vor Beginn eines neuen Produkts werden diese Fragen beantwortet:

1. Braucht das Produkt Demo und persönliche Version?
2. Welche Datenbereiche gehören in den zentralen State?
3. Welche Bereiche benötigen dynamische Mehrfacheinträge?
4. Reicht lokaler Arbeitsstand oder wird zusätzliche lokale Spiegelung benötigt?
5. Wird eine vollständige JSON-Masterdatei benötigt?
6. Wird Excel-Ausgabe benötigt?
7. Wird Excel-Datenübernahme benötigt?
8. Wird eine PDF-Endfassung benötigt?
9. Welche Dateinamenkonvention gilt?
10. Welche Aktionen benötigen sichtbare Bestätigung?
11. Welche Akademie-Erklärungen werden als Klappreiter benötigt?
12. Welche Stress-Test-Daten braucht die Demo?
13. Welche Browser und Geräte müssen getestet werden?
14. Welche Engine-Module aus dem Build-Plan werden unverändert übernommen?
15. Welche projektspezifischen Module kommen neu hinzu?
16. Ist eine spätere Offline-/PWA-Version vorgesehen?

Erst nach dieser Auswahl beginnt die projektspezifische Entwicklung.
