Meine digitale & finanzielle Notfallakte

Willkommen. Auf dieser Seite erhältst du die Windows-Version deiner Notfallakte und wirst Schritt für Schritt durch die Einrichtung geführt. Nach der Installation arbeitet die Anwendung lokal auf deinem Computer.

Windows-Version herunterladen

Meine Notfallakte für Windows
Datei: Meine-Notfallakte-Windows-Installation.zip
Wichtig: Für die erstmalige Einrichtung wird eine Internetverbindung benötigt. Danach liegt die Anwendung lokal auf deinem Computer und wird nicht mehr über Edge, Chrome oder Firefox gestartet.

Was wird eingerichtet?

Lokale Anwendung
Die Programmdateien werden auf deinem Windows-PC gespeichert.
Eigener Datenbereich
Deine Arbeitsdaten liegen getrennt von den normalen Browserdaten.
Desktop-Verknüpfung
Du startest die Notfallakte anschließend wie eine normale Anwendung.
Offline nutzbar
Nach der Einrichtung kann die Anwendung ohne Internet verwendet werden.

Installation – Schritt für Schritt

1
Datei herunterladenLade die Datei herunter und speichere sie auf deinem Computer.
2
ZIP vollständig entpackenRechtsklick auf die ZIP-Datei und „Alle extrahieren“ wählen.
3
Installation startenIm entpackten Ordner INSTALLIEREN.cmd öffnen. Windows kann beim ersten Start nach einer Bestätigung fragen.
4
Einrichtung abwartenDie Desktop-Laufzeit und die Notfallakten-Programmdateien werden lokal eingerichtet.
5
Notfallakte startenNach Abschluss erscheint „Meine Notfallakte“ auf dem Desktop. Erstelle anschließend regelmäßig eine JSON-Master-Sicherung.
Warum gibt es zusätzlich eine JSON-Master-Sicherung?
Die Desktop-Anwendung speichert deinen Arbeitsstand lokal. Die JSON-Datei ist davon unabhängig und dient als transportable vollständige Sicherung. PDF und Excel ergänzen diese Sicherung, ersetzen sie aber nicht.
Was passiert, wenn ich Browserdaten lösche?
Die Windows-Desktop-Version verwendet einen eigenen Anwendungsbereich. Das Löschen von Verlauf, Cookies oder Websitedaten in Edge, Chrome oder Firefox soll die installierte Notfallakte deshalb nicht entfernen.
Kann ich die Notfallakte ohne Internet verwenden?
Nach erfolgreicher Einrichtung ja. Die Programmdateien liegen lokal auf deinem Computer.

Sicherheitsprinzip der Akademie

Persönliche Inhalte sollen nicht an einen zentralen Cloud-Dienst übertragen werden. Der Schutz des eigenen Geräts bleibt wichtig: Windows aktuell halten, Gerätesperre verwenden und regelmäßige externe Sicherungen erstellen.
