Gut zu wissen: Der Installationsassistent richtet die Anwendung, den lokalen Datenbereich sowie die Desktop- und Startmenü-Verknüpfung automatisch ein.

Was wird eingerichtet?

Lokale Anwendung
Die Programmdateien werden auf deinem Windows-PC installiert.
Eigener Datenbereich
Deine Arbeitsdaten liegen getrennt von den normalen Browserdaten.
Direkter Start
Du öffnest die Notfallakte anschließend wie eine normale Windows-Anwendung.
Offline nutzbar
Nach der Installation kann die Anwendung ohne Internet verwendet werden.

Installation – Schritt für Schritt

1
Setup herunterladenKlicke oben auf „Windows-Version herunterladen“ und speichere Meine-Notfallakte-Setup.exe auf deinem Computer.
2
Setup startenÖffne die heruntergeladene Datei per Doppelklick.
Wenn Windows „Der Computer wurde durch Windows geschützt“ anzeigt:
Klicke zuerst auf „Weitere Informationen“ und anschließend auf „Trotzdem ausführen“.
Hinweis zu Virenschutzprogrammen: Manche Programme prüfen eine neue Installationsdatei zunächst automatisch. Warte diese Prüfung ab und fahre nur fort, wenn dein Sicherheitsprogramm die Datei zulässt.
3
„Nur für mich“ auswählenIm Installationsassistenten wählst du „Nur für mich“ und klickst auf „Weiter“. Das ist für eine persönliche Notfallakte die empfohlene Einstellung.
4
Installationsordner übernehmenDer vorgeschlagene Installationsordner kann unverändert bleiben. Klicke anschließend auf „Installieren“.
5
Installation abschließenWarte, bis die Installation beendet ist. Lass die Auswahl „Meine Notfallakte ausführen“ aktiviert und klicke auf „Fertigstellen“.
6
Notfallakte startenDie Notfallakte öffnet sich als eigene Windows-Anwendung. Künftig startest du sie einfach über die neue Desktop-Verknüpfung oder über das Windows-Startmenü.
7
Deine Sicherung einrichtenBevor du wichtige persönliche Daten einträgst, nutze die Demo und den Sicherungsablauf. Erstelle anschließend regelmäßig eine JSON-Master-Sicherung an einem geschützten, selbst kontrollierten Speicherort.
Warum zeigt Windows „Unbekannter Herausgeber“?
Windows kann bei neuen, nicht digital signierten Installationsdateien eine SmartScreen-Abfrage anzeigen. Wenn du die Datei direkt über diese offizielle Auslieferungsseite heruntergeladen hast, kannst du über „Weitere Informationen“ und danach „Trotzdem ausführen“ mit der Installation fortfahren.
Warum gibt es zusätzlich eine JSON-Master-Sicherung?
Die Desktop-Anwendung speichert deinen Arbeitsstand lokal. Die JSON-Datei ist davon unabhängig und dient als transportable vollständige Sicherung. PDF und Excel ergänzen diese Sicherung, ersetzen sie aber nicht.
Was passiert, wenn ich Browserdaten lösche?
Die Windows-Desktop-Version verwendet einen eigenen Anwendungsbereich. Das Löschen von Verlauf, Cookies oder Websitedaten in Edge, Chrome oder Firefox entfernt deine installierte Notfallakte nicht.
Kann ich die Notfallakte ohne Internet verwenden?
Ja. Nach erfolgreicher Installation liegen die benötigten Programmdateien lokal auf deinem Computer. Die Notfallakte kann anschließend auch ohne Internetverbindung gestartet und verwendet werden.
Wo bleiben meine persönlichen Daten?
Deine persönlichen Eingaben werden lokal in der installierten Anwendung verarbeitet. Sicherungen und Exporte wie JSON, Excel und PDF speicherst du selbst an dem von dir gewählten Speicherort.

Sicherheitsprinzip der Akademie

Deine persönlichen Inhalte werden lokal auf deinem Gerät geführt. Schütze deshalb deinen Computer mit einer Gerätesperre, halte Windows aktuell und erstelle regelmäßig eine externe JSON-Master-Sicherung.

Nach der Einrichtung: Nimm dir in Ruhe Zeit für deine Notfallakte, prüfe den Demo-Ablauf und lege deine JSON-Master-Sicherung an einem geschützten, selbst kontrollierten Ort ab.
