# Gemeinsame Simulator- und PDF-Technik

Hier werden erst beim ersten Branchenbaustein benötigte gemeinsame Komponenten ergänzt. Die fachlichen Beispieldaten der vier bereits bestehenden Branchen kommen aus `../../merchant-kompass/handel.html` und dürfen nicht stillschweigend verändert werden.

Die freigegebene gemeinsame Akademie-PDF-Übergabe liegt bereits unter `../../merchant-kompass/akademie-pdf-uebergabe.js`. Nicht duplizieren und keinen Ersatzgenerator entwickeln. Der HTML-Inhalt muss vollständig aus der jeweiligen aktuellen Branchenseite erfasst werden; vor Freigabe jede Seite separat testen.
